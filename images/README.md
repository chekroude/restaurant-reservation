# Captures d'écran à ajouter

Une fois le projet lancé en local (backend + frontend), ajoute ici des captures d'écran :

- `login.png` — page de connexion / inscription
- `home.png` — liste des restaurants (page d'accueil après connexion)
- `reserve.png` — formulaire de réservation
- `history.png` — historique des réservations

Comment faire une bonne capture :
1. Lance le projet en local (voir README.md à la racine)
2. Ouvre chaque page dans le navigateur
3. Fais une capture d'écran propre (sans barre d'adresse visible si possible)
4. Enregistre l'image dans ce dossier avec le nom exact indiqué ci-dessus
5. Elles s'afficheront automatiquement dans le README

Supprime ce fichier une fois les vraies images ajoutées.
